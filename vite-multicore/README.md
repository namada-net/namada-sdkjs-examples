# Namada Multicore SDK with Vite

This example demonstrates instantiating the multicore build of the SDK in a Vite project.

See [vite.config.ts](./vite.config.ts) to view usage of the `@namada/vite-esbuild-plugin`, needed only for
using multicore worker helpers in development mode.

## Usage

```bash
npm install
npm run dev
```
